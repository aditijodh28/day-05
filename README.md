## Project

### Employee Dashboard

The Employee Dashboard is a JavaScript-based employee management application.

## Features

* Display employees
* Search employees
* Filter by department
* Sort employees
* View employee information
* Add employee
* Edit employee
* Delete employee
* Calculate total salary
* Display employee statistics
* Responsive interface
* Reusable JavaScript functions

## Technologies Used

* HTML5

## How to Run

### JavaScript Practice

Open PowerShell in the `javascript` folder.

```bash
node fundamentals.js
node array-methods.js
node advanced.js
```

### Employee Dashboard

Open:

```text
employee-dashboard/index.html
```

in a web browser.
